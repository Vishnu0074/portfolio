03 — How I workBuild / ship / refine

Good software is a series of deliberate decisions.

I start with the user journey, then work backwards into architecture. I prefer simple systems that are easy to reason about, expressive interfaces, and motion that communicates rather than distracts.

01 / DISCOVER

Understand the real problem

Flows, edge cases, roles, API boundaries and what actually needs to happen on a phone.

02 / BUILD

Structure before polish

Clean architecture, state management and reusable UI foundations before the screen-by-screen finish.

03 / REFINE

Make it feel finished

Motion, loading states, empty states, error recovery and the details people notice without naming them.

04 / SHIP

Production is part of the product

Testing, store builds, release configuration, notifications, links and the boring things that make launch possible.
